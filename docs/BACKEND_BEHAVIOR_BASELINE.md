## 本轮实现边界

- 未新增任务管理器、资料调度器、数据库表、依赖或计算执行链。共享组件仍为 2.2.2，同产物不重打包；仅 Vue 宿主文案与下载管理接线修改。

- 手动重跑、历史任务、真实资料、已发布产品、环境与保留策略未被修改；用户暂缓的专属真实第二次尝试继续未执行。
